# 空间工作台：S1 人工交付服务

这是与现有 CloudStudio 和演示展厅隔离的工作空间，包含账号、项目、浏览器文件夹上传、人工处理后台、成果交付及用户主动公开。当前不自动运行 S1 求解或生成模型：用户勾选的是交付需求，由处理团队下载原始数据、本地处理后回传。

## 使用边界

- 单个项目的原始数据（含后续补充）不超过 **5,000,000,000 字节**；用户的原始数据、成果和未完成上传的预留合计不超过 **20,000,000,000 字节**。成果单次上传也限制 5 GB。
- 浏览器先计算完整分片指纹，再上传；恢复时需重新选择原目录，已上传及待上传的分片都与初始指纹核对。目录结构保留，完成时服务器重新读取校验并记录文件 SHA-256。
- 项目和原始数据默认私有。管理员确认交付后，客户才看到新成果；公开由客户主动开启，可随时撤回，原始数据不公开。公开期间不能追加成果。
- 支持图片、PDF 和不超过 150 MB 的自包含标准 GLB 预览；带外部资源、特殊压缩或更大模型请下载查看。IFC、CAD、SketchUp 等成果以文件下载交付，不宣称已在线转换。
- 工作台账号独立于 CloudStudio。忘记密码需由处理团队线下核实身份后重置临时密码，用户下次登录必须修改；没有虚构邮箱验证或自动找回。

## 运行与运维

需要 Python 3.6 或更新版本，运行时只使用标准库。后台仅绑定本机回环地址，公网必须经 HTTPS 反向代理；代理应覆盖 `X-Real-IP`，限制请求体约 17 MiB、关闭请求体缓冲，并禁用包含分享令牌的访问日志。

```powershell
python -m server.app --data <独立数据目录> --origin http://127.0.0.1:8840 --port 8840 --min-free 0
```

本地调试地址是 `/workspace/`。管理员由服务器运维通过 `python -m server.admin_cli --data <数据目录> --username <账号>` 创建，初始密码从标准输入传入，首次登录必须修改。不要把密码放在命令行、日志或代码库。

生产示例的全站工作台数据上限为 80 GB，并在共享磁盘保留至少 20 GB；这是整机容量保护，不改变单用户 20 GB 上限。管理员界面显示备份状态及剩余磁盘。磁盘容量有限时，即使用户个人额度尚未用完，也可能暂时无法创建新上传。

`python -m server.backup backup --data <数据目录> --backup <同机独立目录>` 使用 SQLite 在线备份和独立分片副本，并逐块校验；失败时保留上一成功快照。删除/取消请求对应的备份副本会在下一次成功备份后清理。同机备份不能防止整机或磁盘损坏。恢复命令 `python -m server.backup restore --backup <备份目录> --target <全新目录>` 不覆盖现有数据，恢复副本默认撤销所有会话和公开链接；恢复到线上之前必须人工核对快照后发生的删除和撤回。

## 测试

在本目录运行 `python -m unittest discover -s tests -v` 和 `node --test frontend/tests/preflight.test.cjs`。测试使用临时合成数据。发布时只打包运行时白名单，不包含测试、个人配置、密码或任何真实扫描数据。
