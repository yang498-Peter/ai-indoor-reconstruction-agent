# Security and data handling

- Keep this repository private unless every capture, photo, path and derived geometry has been approved for public release.
- Never commit credentials, registration codes, customer names, raw capture media or machine-specific absolute paths.
- Treat point clouds and posed photos as customer data even when downsampled.
- Use the repository validation script before every push.
- If sensitive data is committed, stop sharing, revoke exposed credentials, and rewrite history before adding collaborators.
