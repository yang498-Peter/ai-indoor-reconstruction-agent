# 室内重建 Skills：全景工具与交互检查

## 问题与范围

工作树中存在全景转透视工具、案例记录及多组未完成工程改动。全景投影本身可以独立复用，但原脚本没有防止输出覆盖冲突，视角方向和极点处理也需要明确。本次从案例中的实际交互问题提炼通用检查，不提交客户数据、截图、发布地址或案例布局。

## 修改文件与内容

- `scene-core/panorama_rectilinear.py`：提供全景转透视接触表；明确正俯仰朝上，避免极点跨越采样，支持 Unicode 路径并拒绝输出覆盖和同名冲突；小尺寸视图不绘制可能覆盖图像的标签。
- `tests/scene-v2/test_panorama_rectilinear.py`：用合成图验证方向、极点、输入保护和路径行为。
- `.github/workflows/presentation-skills.yml`：在 Windows 与 Linux 技能工具检查中纳入全景投影测试及其变更触发路径。
- `.codex/skills/reconstruct-indoor-scene/references/panorama-pointcloud-fusion.md`：说明可移植调用方式、图像视角与世界方位的区别和证据记录边界。
- `.agents/skills/reconstruct-indoor-scene/references/surface-deviation-reporting.md` 与 `interactive-showcase-polish.md`：补充筛选与显示一致性、会话恢复和适配现有展示界面的检查。

## 验证与状态

本地全景工具合成测试 12 项通过，技能格式、链接及便携仓库检查通过；Windows/Linux 托管结果以本次 PR 检查为准。投影结果不是姿态验证、三维测量、客户数据验收或施工结论。没有把案例特定的阈值、坐标、模型或未验证的本地工程化改造作为通用规则。

本地分类：案例工作记录、演示目录与运行输出留在工作树；带具体阈值的结构/楼层实验、重写审核状态的家具碰撞脚本及打包/MCP 工程化改动未作为本次通用技能发布。此前遗留的旧版展示 CI 会缩减测试和平台覆盖，也没有纳入公开候选。
