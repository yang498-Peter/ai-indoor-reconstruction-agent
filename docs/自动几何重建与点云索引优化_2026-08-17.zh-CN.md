# 自动几何重建与点云索引优化记录（2026-08-17）

## 问题现象

- 同一 LAS/LAZ 在总览、立面和局部复核阶段被反复全量扫描，局部检查成本随点数线性增长。
- 墙体主方向、平行墙面和厚度主要依赖 Agent 逐段判断，缺少可复现的几何候选层。
- Scene V2 缺少与原始点云绑定的墙面残差、覆盖率和连续缺失区间，视觉通过不能直接证明几何通过。
- 上游 Argus 的深度与相机能力存在非商业权重限制，不能直接作为商业产品中的几何权威。

## 修改内容

1. 新增只读 CaptureIndex：原始 LAS/LAZ 只流式读取一次，按源坐标米制网格生成原子发布的派生瓦片；大投影坐标以 float64 原点加 float32 局部偏移保存。
2. 新增结构候选器：在结构高度带中提取线段、聚类主方向、配对平行墙面，并把原始观测与建议中心线分开输出；所有结果保持 `candidate`，不得静默改写 Scene V2。
3. 新增点云—场景指标：按墙体计算点到墙面 P50/P90、长度覆盖率和最长连续无支撑区间；`accepted + measured` 墙体不达阈值时为阻断，推断与候选构件仅提示。
4. 指标输出绑定精确场景 SHA-256、索引指纹和索引清单 SHA-256，避免旧报告误用于新场景。
